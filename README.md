리포지토리 개요
AI의 도움을 받지않고, 오직 인터넷 검색과 서적을 통해서 정보를 서치하여 하루 한 번의 commit을 제출하는 리포지토리.

commit제출 규칙
그저 일일 제출 의무를 지키기 위해 실질적으로 프로젝트 진행에 도움이 되지않는 docs문서 수정 등의 commit은 인정하지 않는다. 
기능적으로 도움이 되거나 깃허브 사용법등을 익힐 수 있는 커밋에 한해서 일일 커밋 할당량으로 인정한다.

프로젝트 설정
구현하는 프로젝트는 클론 코딩을 주축으로, 그 뼈대에 원하는 기능을 붙여나가는 식으로 진행한다. 
프로젝트는 산개적으로 여러개를 진행하는 것이 아닌, 하나의 프로젝트가 MVP가 될 때까지 구현했을 때 다른 프로젝트의 진행을 고려해보는 식으로 진행한다.

기타 참고사항
One Day One Commit 프로젝트에서 가장 중요한 것은 프로젝트 관리 능력 향상이다. 이를 위한 깃허브 사용법 관련 내용은 Github Tips 문서에 작성한다.
